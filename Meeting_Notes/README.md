# Meeting Notes

This folder contains all meeting notes and documentation related to team meetings, Vallancourt meetings, and project review sessions.

## Contents
- Team meeting minutes
- Progress review meetings
- Decision logs and action items

## Format
All meeting notes should follow a consistent format with date, attendees, agenda, and action items clearly documented.

Format should follow this format:

Name of the file is 'date of meeting-team/vallancourt'.md for example:
9-26-25-team.md is a team meeting on September 26, 2025
9-30-25-vallancourt.md is a meeting with Professor Vallancourt on September 30, 2025

All attendees should be listed.
A 'table of contents' should be at the top listed all topics covered
If necessary, there will be subsections with more information about each topic
A clear 'Action Items' subsection detailing what all team members should do following the meeting
