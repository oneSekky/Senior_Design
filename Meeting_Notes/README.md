# Meeting Notes

This folder contains all meeting notes and documentation related to team meetings, Vallancourt meetings, and project review sessions.

## Contents
- Team meeting minutes
- Progress review meetings
- Decision logs and action items

## Format
All meeting notes should follow a consistent format with date, attendees, agenda, and action items clearly documented.

Format should follow this format:

Name of the file is 'date of meeting'.md, if it was a meeting with Vallancourt
