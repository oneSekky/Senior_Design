# Process for collecting letter samples

- Collect single letter samples, one letter at a time
- name each sample 'letter#', such as 'a1' or 'b3'
- put all leters in the folder titled alphabet
- see the folder Process_Images/ for screenshots on the specific settings and buttons to press in MEMS Studio
- The board is STEVAL-MKI229A (LSM6DSO16IS)
- Accelerometer data rate: 104Hz
- Gyroscope data rate: 104Hz
- ENSURE NEITHER ARE POWERED DOWN
